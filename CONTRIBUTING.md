# Contributing

Contributions are welcome.

## Development

```sh
cd app
flutter create --platforms=android,ios,web .
flutter pub get
flutter analyze
flutter test
```

## Pull Requests

- Keep changes focused.
- Add or update tests for behavior changes.
- Run formatting, analysis, and tests before opening a pull request.
- Do not commit credentials, private signing keys, generated release artifacts, or event data containing personal information.

AI assistance may be used for implementation, tests, documentation, or review. Contributors remain responsible for validating generated changes and ensuring they have the right to contribute them.
